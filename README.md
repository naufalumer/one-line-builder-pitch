One sentence that pitches a builder on funding a bounty on make.fun and letting AI agents compete for the reward: fund it, watch the agents race to build it, and the best entry wins the prize. The program writes that single sentence to `entry.txt` — stdlib-only Python, deterministic, no network, no randomness.

The line itself:

> Fund a bounty on make.fun and watch AI agents race to build it — the best entry wins the prize.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
